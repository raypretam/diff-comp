┌─ TRAINING ─────────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. Edit training script:                                                   │
│     - Open: run_necti_coarse.sh OR run_necti_finegrain.sh                  │
│     - Find: USE_CONTEXT line                                                │
│     - Set:  USE_CONTEXT=""              (for Without Context)               │
│        OR:  USE_CONTEXT="--use_context" (for With Context)                  │
│                                                                              │
│  2. Run training:                                                           │
│     ./run_necti_coarse.sh                                                   │
│                                                                              │
│  3. Model saved to:                                                         │
│     saved_models/necti_Coarse_no_ctx/    (without context)                  │
│     saved_models/necti_Coarse_with_ctx/  (with context)                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ INFERENCE ────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Usage: ./run_inference_necti.sh [granularity] [context_mode]              │
│                                                                              │
│  Examples:                                                                  │
│    ./run_inference_necti.sh coarse no_ctx      # Without context            │
│    ./run_inference_necti.sh coarse with_ctx    # With context               │
│    ./run_inference_necti.sh finegrain no_ctx   # Fine-grained, no context   │
│    ./run_inference_necti.sh finegrain with_ctx # Fine-grained, with context │
│                                                                              │
│  Results saved to:                                                          │
│    inference_results/necti_Coarse_no_ctx/    (without context)              │
│    inference_results/necti_Coarse_with_ctx/  (with context)                 │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ PYTHON COMMANDS ──────────────────────────────────────────────────────────┐
│                                                                              │
│  Training WITHOUT context (default):                                        │
│    python trainer_necti.py \                                                │
│      --config_file necti_coarse_xlmr.yaml \                                 │
│      --granularity Coarse \                                                 │
│      --data_path "/home/pretam-pg/DepNeCTI/data/NeCTIS Model Data"         │
│                                                                              │
│  Training WITH context:                                                     │
│    python trainer_necti.py \                                                │
│      --config_file necti_coarse_xlmr.yaml \                                 │
│      --granularity Coarse \                                                 │
│      --data_path "/home/pretam-pg/DepNeCTI/data/NeCTIS Model Data" \       │
│      --use_context                                                          │
│                                                                              │
│  Inference WITHOUT context:                                                 │
│    python inference_necti.py \                                              │
│      --model_path "./saved_models/necti_Coarse_no_ctx/best_model.pt" \     │
│      --granularity Coarse \                                                 │
│      --splits test dev ood                                                  │
│                                                                              │
│  Inference WITH context:                                                    │
│    python inference_necti.py \                                              │
│      --model_path "./saved_models/necti_Coarse_with_ctx/best_model.pt" \   │
│      --granularity Coarse \                                                 │
│      --use_context \                                                        │
│      --splits test dev ood                                                  │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
